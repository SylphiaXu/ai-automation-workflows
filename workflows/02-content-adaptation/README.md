# 02 · 一个洞察，三种形式

**状态：流程设计，未实现自动运行。**

| 项目 | 设计 |
| --- | --- |
| 触发方式 | 人工提交已复核的洞察 |
| 输入 | 洞察、证据、目标受众、平台、语气与限制 |
| 输出 | 图文草稿、短视频脚本、长文案 |
| 人工检查点 | 事实、表达、平台适配、品牌与个人语气 |
| 不自动化的部分 | 最终选题、敏感宣称、发布与账号操作 |

同一事实在改写时不能新增未经支持的数字、经历或功效。输出保留证据引用与待确认项。

## 实现后要验证
三个版本是否保留同一事实，信息是否适合各形式，人工修改量与完成时间如何。无真实运行前不宣称提效。
