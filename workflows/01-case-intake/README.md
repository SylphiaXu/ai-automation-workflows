# 01 · 营销案例收集

**状态：流程设计，未实现自动运行。**

| 项目 | 设计 |
| --- | --- |
| 触发方式 | 初期手动运行；定时运行待实现和验证 |
| 输入 | 明确的来源清单、研究范围和覆盖日期 |
| 输出 | 品牌、动作、原始上线日期、报道 / 新进展日期、来源链接、待核验项 |
| 人工检查点 | 核验事件与来源，判断是否值得深拆 |
| 不自动化的部分 | 最终案例选择、未核实效果判断、对外发布 |

日期若采用“昨日”口径，按 Asia/Shanghai 的自然日定义，并明确覆盖日期。旧案例的新报道不能自动算作新案例。

## 实现后要验证
来源能否访问、日期是否正确、旧闻是否被误收、是否重复、原文是否支持摘要。失败时输出缺失与错误，不补造案例或链接。
