# 03 · 每周社媒聆听汇总

**状态：流程设计，未实现自动运行。**

| 项目 | 设计 |
| --- | --- |
| 触发方式 | 初期手动提交一周数据；周期任务待验证 |
| 输入 | 授权来源、明确时区与时间窗、话题范围和上期可比样本 |
| 输出 | 主题、情绪分布、证据示例、变化与不确定性说明 |
| 人工检查点 | 抽样偏差、主题相关性、引用、趋势解释 |
| 不自动化的部分 | 趋势最终判断、品牌行动决策、对外发布 |

上升与下降需要可比的采样覆盖和分母。平台、采样方式或数据量变化时先标记，不把样本频次直接视为市场需求。

## 实现后要验证
去重质量、主题归类、情绪误判、引用可追溯性与人工抽检结果。没有可比样本时只描述当期，不输出趋势结论。
